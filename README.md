# DevOps Exercises – Kubernetes, Docker, Grafana and Jenkins

## Overview

This repository contains 10 hands-on DevOps exercises covering containerization, Kubernetes orchestration, Docker networking and security, monitoring, and CI/CD automation using Jenkins.

## Exercises List

| No. | Exercise | Description |
|---:|---|---|
| 1 | Kubernetes Getting Started | Introduction to Kubernetes concepts and basic cluster operations. |
| 2 | Minikube, Kubectl and Flask | Deploy a Flask application to a local Kubernetes cluster using Minikube and kubectl. |
| 3 | Minikube Scaling Flask App | Scale a Flask application by adjusting Kubernetes replicas. |
| 4 | Docker Networking | Explore Docker networks and communication between containers. |
| 5 | Docker Security with AppArmor | Understand container security and AppArmor profiles. |
| 6 | Grafana Real-Time Monitoring | Set up monitoring and visualize real-time metrics using Grafana. |
| 7 | Jenkins CI Automation | Install Jenkins and understand continuous integration workflows. |
| 8 | Jenkins Hello World Job | Create and execute a basic Jenkins job. |
| 9 | Jenkins Multi-Stage Pipeline | Configure a Jenkins pipeline with multiple stages. |
| 10 | Minikube Multi-Node, Multi-Container | Explore multi-node Kubernetes clusters and deployment of containerized applications. |

## Prerequisites

Install the tools required for the exercises you intend to run:

- Docker Desktop
- Minikube
- kubectl
- Jenkins
- Grafana
- Python and Flask
- Git and GitHub

Some exercises may require additional configuration depending on your operating system and environment.

## How to Use This Repository

1. Clone the repository.
2. Open the exercise corresponding to the topic you want to practice.
3. Review the instructions and prerequisites.
4. Execute the commands and configurations in your local environment.
5. Verify the results and capture screenshots where required.

## Learning Outcomes

After completing these exercises, you should understand:

- Container creation and management using Docker.
- Kubernetes deployments, services, scaling and multi-node clusters.
- Container networking and security fundamentals.
- Application monitoring using Grafana.
- Continuous Integration and automated jobs using Jenkins.
- Multi-stage CI/CD pipeline concepts.
